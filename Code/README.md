# README file for Code
This folder contains the `functions` folder, where all Python modules and functions necessary to successfully reproduce and run code in this repository are stored.

Furthermore, there are Jupyter notebooks containing fitted Bayesian models for each Dataset and each baseline or selection of participants separately. These were run and contain all cell outputs. Each notebook also contains a watermark to allow full reproducibility.

Note:
I used the label `task` in the notebooks for memory conditions. This is used in the model definition as well.

Data and Figures (including code to produce the figures) are stored separately in the corresponding folders. See the general readme for more information.
